# 超级火花手镯

## 首版规则

- 六阶装备，编号118，凶器、饰品标签；保留原名称、价格和简介。
- 穿戴后每累计30秒战斗时间生成一枚火花，首次也是等待30秒，不在刚进场时立即发射。
- 火花持续5秒，在玩家周围约90距离高速环绕（角速度12弧度/秒），跟随玩家移动，不主动突刺。
- 每次命中150基础火焰伤害，加当前玩家智力50%；玩家已明确将基础伤害由建议的30提高至150，其余参数沿用建议首版。
- 可穿透并命中多个敌人，同一枚火花对同一敌人每0.4秒最多命中一次。不暴击、不削韧、不自动施加燃烧，不攻击地图物件。
- 升级态暂按本项目“护甲对应固定减伤”的定义实现：玩家自身造成的伤害跳过目标固定减伤，百分比减伤、易伤、闪避与护盾照常。该范围尚未收到玩家对第二个问题的明确回答，后续可以独立调整。
- 不自动把穿透赋给召唤物；默认不改变自伤成本。是否跳过百分比减伤、是否影响自伤、伤害标签及类型筛选均有独立导出配置。

## 生命周期与命中

周期计时放在战斗实体下的独立运行器中；常驻构筑代理不生成火花。普通装备效果重建时先停用、再同步启用，延迟清理，因此不会因购物、获得临时弹药或普通装备刷新重置30秒倒计时，也不会重复叠加运行器。

真正卸下装备时停止计时并清理当前火花；玩家死亡、战斗结算或切场景时也清理。新战斗重新计时，暂停时不累计时间。

高速巡航除Area2D重叠检测外，还沿移动路径进行扫掠，并把大角度移动拆成短弧，减少低帧率漏击；两类判定共享命中间隔。单帧最多16段，避免严重卡顿时无限补算。大幅传送不沿整条迁移线造成伤害。

伤害穿透使用DamageData标记和StatsController的独立来源注册，不修改敌人属性，也不通过追加伤害模拟“补回护甲”，避免额外命中事件或递归。所有未注册穿透的原有伤害仍沿用原减伤步骤。

## 配置入口

- 装备：`relics/level_6/118_超级火花手镯.tres`，Patrol子资源调整周期、寿命、基础伤害，IgnoreArmor子资源调整穿透范围。
- 火花场景：`scenes/ability/manifest/orbiting_spark_manifest.tscn`，调整半径、速度、命中间隔、范围和智力公式。
- `PeriodicOrbitingManifestEffect`只负责装备注册；`PeriodicOrbitingManifestRunner`负责计时、生成与清理。
- `OrbitingProjectileManifest`复用现有飞剑环绕，再补高速巡航扫掠，不改原飞剑表现。
- `OutgoingDefenseBypassEffect`仅负责注册/撤销防御穿透，可复用于其他装备。

新脚本均有中文说明。美术复用已有 `assets/shockwavespritesheets/spark.png` 的一个32像素帧，暖色shader重映射与现有淡拖尾增强表现。保留Sprite2D供替换贴图，没有调用素材API，没有使用上一轮余额。

## 手动验收

1. 调试台添加并穿戴手镯，在有敌人的战斗中等待30秒，确认只出现一枚火花，5秒后消失，再累计到60秒时出现下一枚。测试时可临时把装备Patrol.interval改成3，测试结束改回30。
2. 靠近火花轨道，确认150基础伤害加智力50%，可穿过多个敌人；同一敌人不能每帧受伤，地图物件不受伤。不要把所有150点都理解为最终扣血：普通态仍有目标减伤和其他伤害修饰。
3. 火花持续期间移动、暂停、恢复，观察跟随、拖尾与暂停。低帧率下检查弧线路径命中；传送后不应沿整张地图形成伤害线。
4. 周期倒计时中触发一次普通装备刷新（如获得临时弹药），确认不会重新等待完整30秒；持续期间刷新也不应删除后重新生成火花。
5. 真正卸下时火花消失且停止生成；战斗结束、玩家死亡和切场景无残留，下场战斗重新计时。
6. 对相同敌人比较普通态与升级态。若基础伤害150、智力0、目标固定减伤10和百分比减伤50%，不含其他效果时，普通态扣70、升级态扣75。敌人仍可闪避，易伤和护盾仍结算。
7. 升级态用玩家其他技能/自己施加的状态伤害确认同样穿透；召唤物自己的伤害不会自动穿透。卸下后玩家伤害恢复正常减伤结算。
