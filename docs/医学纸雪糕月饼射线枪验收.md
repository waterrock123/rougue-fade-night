# 医学纸、雪糕、月饼、射线枪效果验收

## 规则与当前默认值

- 纸：医学：装备时体质+5；升级态每场战斗仅一次，在死亡结算前永久扣除1点基础体质，并在当前位置恢复扣除后最大生命的20%。装备刷新、卸下重装不会重置次数，多件医学纸也共用本场一次机会。
- 巧克力夹心雪糕：使用后速度、敏捷各+5，持续至战斗结束；升级后基础攻击命中附加当前敏捷50%的冰属性基础伤害，也持续至战斗结束。不额外施加冰冻控制。重复使用不会重复叠加这两种状态。
- 诅咒月饼：装备获得3层护甲和附加毒伤；当前默认包含基础攻击，按技能本次实际伤害的30%生成独立毒属性基础伤害。附加伤害仍接受后续出伤、承伤修正，不自动施加中毒。使用时直接流失5生命并正常消耗月饼。升级态装备期间每5秒受到一次1点物理伤害，该攻击可被闪避或减免，护甲可能将其降为0。
- 外来者射线枪：敏捷+2，具有 projectile 标签的伤害+2；每颗实际发射的投射物独立有5%概率额外发射一束穿透激光，升级概率10%。抛射物、近战特效不触发。当前激光默认基础伤害10、速度1000、距离600，无属性公式、暴击和削韧；会撞墙，单束激光对同一目标最多命中一次。自身投射物+2也作用于激光，因此无其他修正时为12点基础伤害。

雪糕升级已按用户补充实现。月饼是否排除基础攻击、激光具体参数尚待确认；上述配置可以直接在对应资源修改。

## 可复用入口

- `PreventDeathOnceEffect`：死亡前恢复生命；永久代价组合 `UsePermanentStatsEffect`，次数存在当前实体，不写入跨战斗存档。
- `StatusOutgoingExtraDamageEffect`：支持固定伤害、当前属性乘数、实际伤害比例，以及技能槽位包含/排除。额外伤害不触发自身或其他同类附加伤害，避免递归。
- `UseHealthLossEffect`：使用时流失生命，跳过伤害判定，但保持生命同步和死亡/复活入口。
- `ProjectileLaunchSpawnManifestEffect`：监听 `EventBus.projectile_launched`，延迟生成可配置的额外 Manifest。普通、动画、萤火虫三类投射物均已接入通知。
- 激光场景保留 `Sprite2D` 以便添加正式贴图；目前使用轻量 `Line2D` 表现光束。

## 手动测试

1. 普通医学纸装备/卸下：体质准确增加/减少5；普通态不能复活。
2. 升级医学纸第一次致死：不出现死亡界面、位置不变、基础体质永久-1、生命恢复20%；第二次致死正常失败。刷新装备后次数仍已消耗，新战斗可重新使用。
3. 普通雪糕：使用前无加成，使用后速度/敏捷+5；升级雪糕在敏捷20时附加10点冰伤（后续伤害修正前）。更改敏捷后冰伤随之变化；离开战斗后加成不保留。
4. 月饼：装备时护甲+3；技能/基础攻击对存活目标命中后有独立绿色毒伤，不发生连续递归命中；使用流失5生命并移除装备及其常驻效果。使用导致生命归零时，医学纸仍可阻止死亡。
5. 月饼升级：正式战斗中每5秒尝试造成1点自伤，卸下或离开战斗后停止；因护甲减免为0并不代表没有触发。
6. 射线枪：实际发射投射物时触发概率生效，空施法、抛射物不触发；生成的激光沿原投射物方向前进，不跟随后续鼠标变化。临时把概率改为1便于验证，完成后恢复5%/10%。
7. 激光贯穿多个敌人但对每个敌人仅一次；撞墙消失，且不会再次递归生成激光。离开战斗时旧的延迟生成请求和信号监听被撤销。
8. 雪糕、月饼附加伤害造成击杀时，击杀计数只增加一次；已被原攻击击杀的敌人不会再承受附加伤害。
