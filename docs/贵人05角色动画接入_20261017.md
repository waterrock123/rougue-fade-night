# 贵人 05 角色动画

## 本轮范围

采用玩家选定的候选 05：蓝紫长发、蓝金星纹尖帽、蓝金法袍与圆头法杖。
使用项目现有 Meowa API 生成，不替换候选立绘，不改角色属性、初始技能或碰撞。
角色数据仍位于 `character_resource/wizard/wizard.tres`，id 仍为 `wizard`。

## 动画资源

| 动作 | 内容 | 原始播放时长 | 循环 |
| --- | --- | --- | --- |
| idle | 轻微呼吸、头发与袍摆微动 | 2 秒 | 是 |
| run | 原地迈步、袍摆与帽子轻微摆动 | 1 秒 | 是 |
| attack | 向右前方挥杖、收回 | 原片1秒，接入基础攻击后播放0.5秒 | 否 |
| cast | 举杖、手边小型法阵、收势 | 2 秒 | 否 |
| die | 失力跪倒，保持战败姿态 | 2 秒 | 否 |

原图为 32×32，生成前仅增加透明边距到 48×48。API 实际返回 49×49 固定画布，
导入时按真实尺寸拆帧，不强制缩放或逐帧裁切。视觉偏移 `(0.5, 0.5)` 用于奇数画布的像素对齐；
角色显示缩放仍为 1，原碰撞体不变。默认朝右，朝左沿用现有翻转机制。

- 正式素材目录：`assets/人物角色素材/guiren_05/`。
- 动画资源：`sprite_frames/guiren_05_sprite_frames.tres`。
- 视觉配置：`character_resource/wizard/wizard_visual_data.tres`，已关联到贵人角色。
- 法杖已画在角色帧内，所以 `show_weapon=false`，不再叠加默认剑或枪。
- 第一版攻击含魔法弹且触碰边缘，已保留为 `attack_first_attempt.*`，正式资源使用纯动作修正版。
- 原始动画 WebP、图集、时长元数据和动作预览均保留。
- 完整提示词在 `custom_resource/meowa_guiren_05_*_20261017.json`，本轮没有额外生成角色立绘。

技能只需通过原来的动画组件播放 `attack` 或 `cast`，真实弹体、伤害和施法方向仍由技能组件处理。
这里不新增贵人的技能设计，也不将动画中法杖朝向与鼠标实时瞄准混为一体。

## 预算

动画任务独立预算上限 150 点，不计入此前候选图的 50 点预算。
首轮五段每段 15 点，攻击修正版另外 15 点，实际账单已核对，总额 90 点，余下 60 点未使用。
实际计费和任务状态见 `custom_resource/meowa_guiren_05_animation_assets_20261017.json`。

## 测试方式

只使用编辑器扫描和隔离检查，不启动战斗、不改存档。

1. 打开 SpriteFrames 资源可逐个预览五段动画。
2. 在大厅选择贵人，检查待机、左右移动和角色 NPC 的外观。
3. 实战中用动画组件触发 `attack`、`cast`，检查其和技能结算时刻的匹配。
4. 检查战败后停在末尾姿势并走原有死亡流程，不会无限循环战败动画。

隔离校验脚本：`scripts/utils/guiren_art_editor_check.gd`。
检查角色关联、循环、时长、图集尺寸，以及战斗/大厅精灵节点和现有视觉接口的引用。
编辑器中的非 tool 游戏节点只作静态资源检查，不调用其占位脚本；实际移动、技能播放和死亡流程仍需手动实测。
另用离线工具核对透明度、图集逐像素一致性及画布边缘。

最终结果：正式动画共 60 帧，五段离线检查全部通过；贵人资源及接口检查 40 项、
已有冰原动画回归 80 项均通过。未运行实战。编辑器退出仍有现有石头投射物 UID 与
RID/ObjectDB 清理日志，本次未处理这些独立问题。
