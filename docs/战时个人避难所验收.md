# 战时个人避难所

## 规则
- 普通态装备期间：速度-4、百分比减伤+20个百分点，卸下撤销属性加成。
- 穿戴时死亡：回收背包和装备栏的全部非临时装备，包括避难所自身；只有放在背包不生效。
- 仍需解锁拾荒仓库。仓库空间足够时一次性写入；不足时复用通关后的装备保留界面，可换掉仓库旧装备，不能丢弃锁定条目。
- 升级态额外临时解锁3个背包格，而不是3个穿戴格。卸下后按原锁格机制恢复：其中的装备仍能取出整理，但离开修整期时会被清理。
- 多个避难所不重复回收同一批装备；没有避难所时仍随机回收一件，普通死亡的满仓规则不变。
- 仓库保存失败时显示错误并允许重试，保存成功后才删掉本局检查点，进入死亡界面。

## 实现分工
- 属性与升级容量直接复用 AddStatEffect、AddDerivedStatEffect、AddInventorySlotsEffect。
- 新增 DeathRecoveryPolicyEffect 是声明式策略资源，recovery_count=-1为全部，正数为随机回收件数，0为默认规则。
- PlayerBuild只查询已穿戴装备的基础效果，以及升级态的升级效果；Run负责统一死亡结算。策略本身不监听死亡信号、不直接操作存档。
- VictoryRelicSelectionPanel增加死亡模式标题和按钮文案，保留原胜利入口、独立多选和锁定保护。
- DeathScreen只展示实际新增回收件数，不把整背包装备名字展开撑大界面。

## 手动验收
1. 装备普通避难所，检查速度-4、减伤率+20个百分点；卸下后恢复。
2. 背包正常可用格数量记为N，穿戴升级态后为N+3；刷新装备效果、进入战斗、续档不会重复增加，卸下后回到N。
3. 已解锁且容量充足时携带数件装备死亡，检查背包与穿戴装备都入库，升级态保留，临时装备不入库，避难所自身入库。
4. 仓库接近满时死亡，在保留界面独立勾选多件装备、取消旧装备，确认后进入死亡界面；锁定仓库装备始终保留。
5. 避难所只放在背包时死亡，仅按普通规则随机回收一件；未解锁仓库时不回收。
6. 同时穿戴多个避难所死亡，入库数量不翻倍；再检查通关时原来的保留装备交互不受影响。
