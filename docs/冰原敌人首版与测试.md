## 战斗行为

### 霜牙猎犬

- 180距离内起手，先锁定方向并显示直线预警0.6秒。
- 沿锁定方向冲刺180距离、耗时0.35秒；移动使用物理碰撞，撞墙停止，不在冲刺中追踪目标。
- 同一次冲刺每个目标最多受到一次14基础物理伤害，有效命中附加1.5秒冰霜减速。
- 完整移动锁1.5秒，冲刺后留下约0.55秒恢复机会；技能冷却3.8秒。
- 不是悬赏怪、不保持中立、不保留原大狗红眼和叫声音效。

### 冰晶哨兵

- 最大施法距离260；被接近到100距离内时尝试寻路后撤，施法与控制期间不会后撤。
- 起手锁定方向，预警0.55秒。分别在0.55、0.73、0.91秒发射一枚冰锥，方向偏移-18、0、+18度。
- 冰锥速度160、距离310、每发9基础冰/远程伤害，不穿透，被World墙体挡住。
- 命中提供1秒减速，不继承玩家冰锥的概率冻结与幸运加成。
- 移动/朝向锁1.35秒，冷却2.8秒；玩家可以利用弹幕间隙、掩体和绕侧接近。

### 背冰兽

- 转向速度1.2弧度/秒，在65距离内起手，锁定当前朝向1.7秒，不瞬间转向玩家。
- 先获得1秒冰壳防御：正面120度的直接伤害降低60%，有淡蓝扇形和本体色调提示。
- 侧面/背面、地形、持续伤害、自伤、反伤不被这项正面防御削减。
- 0.75秒开始显示红色扇形预警，1.1秒对前方65距离、110度范围挥击，造成18基础近战伤害。
- 防御结束后有攻击/恢复阶段，不是永久免伤。硬直和破韧立即取消旧动作、防御和排队伤害。
- 冷却4.5秒，玩家可以绕背、诱导挥击或破韧打断。

## 通用扩展

- `ConfiguredEnemy`：复用旧场景并替换战斗技能，提供二维朝向锁、慢速转向和可选后撤；只影响使用该脚本的新变体。
- `AbilityPhysicsCharge`：锁定方向的物理冲刺，不负责伤害。
- `AbilityLockFacing`：只负责锁定朝向。
- `AbilityDamageStatusWindow`：监听指定技能的有效出伤事件，在命中窗口内施加状态。
- `StatusRemoveOnActionCancelEffect`：动作被取消时撤销绑定的状态。
- 扇形生成组件新增整组角度偏移，默认0，已有技能行为不变。
- 承伤状态新增可选正面角度，默认关闭；依然走统一伤害结算。动画投射物补充真实命中方向。

## 手动测试

1. 建议新开一局并进入第二层，确认三种敌人出现；旧存档里已经保存的具体战斗配置不保证被重新抽取。
2. 单独测试时，在现有BattleWaveData的fixed_spawns中填入对应新场景、count=1，并将随机池max_enemies设为0。
3. 猎犬：预警后横向躲开，确认不追踪；贴墙诱导冲刺，确认不穿墙；蓄力/冲刺中击杀，确认不会继续伤害或移动。
4. 哨兵：确认三发角度不同且先后射出；利用墙体挡弹；靠近观察后撤，在窄路观察是否能正常攻击。
5. 背冰兽：比较正面和背面伤害；确认防御仅1秒，挥击方向保持锁定；硬直/破韧后旧预警和伤害应结束。
6. 暂停、返回大厅和继续游戏，观察是否有离树协程报错、遗留预警或防御状态。
7. 检查三种怪物的死亡动画均能结束并释放；占位动画中的walk/move别名仅在新实例中修正。
