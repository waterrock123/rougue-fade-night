# 浪子战斗技能

## 交互细节

- 贯甲射击按住技能键显示直线预览，松开释放。没有弹药并不等于无需能量，始终需要8能量。
- 弹药优先由附近可用弹药箱支付，否则消耗背包第一件符合弹药标签的装备；与眼镜蛇大炮使用同一套成本组件。
- 可选材料仅为贯甲射击开启。眼镜蛇大炮仍然没有弹药就不能释放。
- 无弹药的伤害减半包括敏捷成长及该次伤害附加，不只是将35基础伤害减半。无弹药版本仍保留贯甲技能的固定减伤穿透。
- 已命中的同一实体及其重复Area不会重复占用贯甲弹的穿透次数；到第5个目标后消失。投射物继续遵守撞墙、无敌目标和闪避规则。
- 弹药箱实际消耗一次也触发余弹利用。仅检查弹药、瞄准取消、释放失败以及无弹药降级施法都不触发。
- 强化次数按“整次基础攻击”扣除，而非按子弹或命中次数扣除。已经飞出的子弹保存释放时增伤，不受剩余次数变化影响。
- 战术装填额外子弹与浪子基础攻击原有的周期额外子弹相加；同来源反复获得强化仅刷新到3次，不叠加伤害倍率。
- 余弹利用、战术装填会显示状态图标，层数是剩余强化次数；最后一次仍生效，但施放后状态立即清除。
- 侧身快枪直接按下释放，方向读取Input Map，支持玩家重新绑定移动按键。滑步中短暂锁移动与其他施法；撞墙提前结束并射击，控制、死亡、战斗结束或移除技能则取消后续链。
- 无敌帧沿用实体机制，不把敌方投射物消除。滑步射出的子弹不是基础攻击，不消耗普攻强化次数。
- 标记同时只保留一个目标，切换目标、到期、战斗结束或场景退出时清理旧标记与增伤。敌人头顶有金色瞄准符号，并附带状态提示。
- 标记增伤登记在标记者的出伤属性上，只针对标记目标，不是所有人共享的易伤。召唤物和其他实体击杀不领取此技能赏金。
- 每场1金币额度位于角色的独立运行节点上，刷新技能栏、卸下再携带技能不会重置；新战斗开始时才重置。
- 见机行事允许基础攻击暴击触发，但地图物件、零伤害、闪避和已标记为不可递归的次级伤害不触发。所有命中共用0.6秒间隔，没有技能在冷却时不储存削减次数。

## 通用实现

- `AbilityConsumeTaggedInventoryRelic.allow_missing_material`：材料成本可选；默认关闭，兼容已有技能。
- `AbilityCastRecord.material_payments`：记录本次真实支付的标签与数量；检查阶段不写入，正式支付和施放复用同一上下文。
- 弹药消耗仍走`RelicConsumption`触发被消耗效果；背包、装备与属性刷新通知延后，避免同步重建技能栏把当前开枪节点移除。
- `AbilityPaymentProjectileProfile`：根据支付结果设置本次伤害倍率、是否穿透和命中上限。
- `LimitedHitProjectileManifest`：有限穿透、同目标一次命中及可配置固定减伤穿透。
- `AbilityLockMovementDirection`：锁定移动输入或鼠标方向。
- `AbilityMoveThenTrigger`：完成物理滑步后执行子组件，不使用跨场景延迟协程。
- `PassiveMaterialBasicAttackEffect`：消耗材料后强化若干次普攻，支持首发额外子弹。
- `PassiveCriticalCooldownEffect`：带间隔限制的暴击削减冷却，可选击杀状态奖励。
- `BountyMarkController`：单目标标记、独立增伤及单场赏金上限。
- `StatsController`出伤修正新增可选`required_target_id`，旧修正没有填写时行为不变。

本轮复用已有子弹和图标素材，没有调用素材生成API。新投射物、滑步后子组件、伤害成长及各被动参数均可在场景或资源检查器中调整。

## 检查方式

仅执行编辑器扫描和真实函数隔离测试，不自动运行游戏。新增检查脚本是`scripts/utils/scount_combat_skills_editor_check.gd`，日志位于`.godot/scount_combat_skills_check.log`。

检查包含资源与奖励池、必需/可选弹药、弹药箱优先、真实支付上下文传递、无弹药半伤害和不穿透、五个不同目标命中、三次普攻强化、首发额外子弹、暴击减冷却与间隔、滑步取消/碰墙、单目标标记和单场1金币上限。

本轮结果：新增浪子检查140项、普攻回归53项、已有法术回归96项、贵人元素联动回归177项、元素快照回归62项，共528项通过，失败0项。日志中没有脚本解析错误；未启动主场景或战斗场景。

## 游戏内验收

1. 使用浪子，打开局内调试器按名称添加技能。三个主动及两个被动均可直接测试，对应升级版可单独添加或通过分支替换。
2. 无弹药释放贯甲射击，确认可开枪、只命中一个目标；添加一件弹药再次释放，确认实际消耗并恢复全伤害、有限穿透。进入弹药箱范围再测，确认只扣箱子次数。
3. 携带余弹利用或战术装填，支付一次弹药，观察3层强化状态，连续四次普通攻击检查只有前三次强化；升级版首发应多一颗，与基础攻击周期奖励可以同时出现。
4. 朝墙、斜方向及无移动输入分别使用侧身快枪，确认滑步不穿墙且滑步后向鼠标三连射；被控制打断时不补发射击。
5. 调试器提高暴击率，先让两个主动技能进入冷却，再持续攻击，检查只削减剩余时间最长的一个技能，密集多弹不会瞬间刷空所有技能。
6. 标记一个敌人后改标另一个，击杀旧目标不领奖，击杀新目标只奖励1金币；本场继续标记击杀不能再得金币，下一场重新允许领取。

编辑器退出时可能继续输出项目原有的UID后备路径及RID/ObjectDB资源清理提示。这些提示与用例结果分开记录，实际手感与完整战斗链路仍需游戏内验收。
