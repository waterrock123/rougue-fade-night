# 混沌发生器实现与验收

## 当前规则

装备资源：`res://relics/level_5/137_混沌发生器.tres`，编号 137，五阶，幻景、洞察标签。未添加美术或使用素材 API。

- 穿戴时：所有随机地图特殊物体的出现概率、生成数量各增加 100%。不包含火海、冰面等特殊地形，不复制模板中手工摆放的物体，不补刷当前已生成地图。概率最高为 100%，实际生成仍受安全位置、间距和可用区域限制。
- 获得时：按现有资源权重触发一项非默认天气或环境，覆盖所选类型，另一类型不变；持续房间数沿用被抽中资源的配置。
- 升级态获得或已有装备升级时：将本局基础一级属性的七项总点数重新分配，再重随机全部永久拥有的非基础攻击、非装备提供主动技能。
- 同一件实例的一次性效果有独立记录。获得通知与原有 `on_gain` 并存，但不重复结算；重穿、装备刷新和续档不重随机。

地图和天气部分暂采用以上建议范围；升级重随机范围已由玩家确认。

## 属性与技能边界

一级属性为力量、敏捷、智力、体质、速度、魅力、幸运。只修改 `PlayerBuild.player_stats`，总和不变；某项可以分配到 0。角色资源、开局属性快照、装备与被动修饰、独立永久属性账本不被重写。生命上限变化后保持生命比例，能量保留实际数值并受新上限夹取。

主动技能重随机保留已携带/未携带状态和槽位，初始技能只替换为初始技能，升级技能只替换为升级技能；遵守角色归属并排除重复。候选不足则保留不能替换的原技能，可在已拥有技能之间交换。基础攻击、临时技能和装备提供技能不变，被动技能不变。技能栏与背包技能面板通过现有技能变更信号同步。

## 复用入口

- `MapObjectGenerationMultiplierEffect`：地图特殊物体生成倍率；分类留空匹配全部特殊物体。
- `GainRandomWorldConditionEffect`：获得时触发天气/环境，可分别开启类型。
- `GainRedistributePrimaryStatsEffect`：获得或升级时重分配指定一级属性，可调整属性子集。
- `GainRerollActiveSkillsEffect`：获得或升级时重随机主动技能，可调整目录、归属与阶段限制。
- `RelicGainRuntimeHelper`：上下文解析、单件去重和属性同步。

新增的 `on_added`、`on_upgrade` 默认为空，不重放其他装备已有的获得效果。合成、营火强化、点器生灵的直接强化已接入升级通知。升级通知与合成免费三选一分开，直接强化不会因此额外获得合成奖励。大厅携带仅在新开局补发获得通知，不对续档重放。

一次性记录使用遗物已有的 `effect_counters`，随局内存档和仓库保存。曾触发过的同一件装备从仓库再次携带也保留记录；新的独立实例仍可触发。保存沿用现有检查点规则，不强制保存战斗或事件中尚未结算的操作。

## 手动测试

1. 调试台添加普通混沌发生器，观察地图界面的天气或环境发生变化；反复穿戴/卸下，确认不会反复抽取。
2. 战斗前穿戴，选择同一模板比较随机物体概率和数量；模板固定物体和特殊地形应不受影响。原概率已为 100% 的物体只能增加数量。
3. 记录七项基础属性总和，以及基础攻击、被动、装备技能和主动技能携带槽位；获得升级态混沌发生器后核对总和不变，只有允许的主动技能改变，图标与释放技能一致。
4. 同时拥有携带与未携带技能时重随机，确认槽位/携带状态保留、归属正确、没有重复。候选不足尤其是升级技能目录暂无候选时，应保留原技能。
5. 以三件普通混沌发生器合成，确认升级效果结算一次、原合成免费三选一仍只获得一次。营火直接强化也应结算升级效果，但不产生合成奖励。
6. 在已有存档检查点退出并继续，确认属性、技能、天气和去重记录保持，不会重新抽取。事件/战斗内退出仍按原检查点回退。
7. 在大厅携带一件尚未触发过的混沌发生器开启新局，确认获得效果执行；已触发实例重新携带不重复执行。
