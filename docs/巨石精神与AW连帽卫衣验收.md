# 巨石精神与 AW 连帽卫衣

## 巨石精神

- 装备者本人击破拥有 `rock` 特征标签的地图岩石时，独立进行一次概率判定。
- 装备者发射的 `stone` 标签投射物首次命中、撞墙、或到达最远飞行距离时进行判定。一颗穿透石头只判定一次，不因后续重复命中或消失再次判定。
- 概率普通态30%、升级态50%。切场景清理、来源死亡和无效方向导致的释放不触发。
- 巨石从被击破/命中的石头位置，沿真实命中方向发射；未提供方向的近战伤害，以装备者到岩石的方向兜底。
- 物理基础伤害30，加当前力量100%，无额外暴击/削韧；穿透，每个目标至多命中一次，撞墙消失。
- 速度暂设300，距离400，可在 `boulder_manifest.tscn` 中调整。场景内 `Sprite2D` 留空，请为它添加巨石贴图；当前不会凭空生成替代美术。
- 地图岩石与投出的石头是两个独立对象：投出的石头击破地图岩石时，两条触发链可以各判定一次。
- 巨石自身不带 `stone` 标签，消失不会再生成巨石；若它击破其他地图岩石，仍可正常触发该岩石的判定。

## AW 连帽卫衣

- 按世界位置的实际位移计算移动速度，而非面板速度。站立、被墙阻挡属于低速；冰面滑行、冲刺等实际位移也计入。
- 严格小于50生效；每0.05秒检查一次条件，只有切换条件时才启用/撤销子效果。
- 连续满足条件0.5秒后发射第一束，此后每0.5秒一束，方向随机。离开条件时停止发射计时，再次满足时重新计时。
- 每束激光为总基础伤害4的物理/冰/火/闪电混合伤害，代表每种基础伤害1；沿用项目现有的多类型伤害包与混合飘字颜色，统一结算一次护甲、减伤与命中效果，不拆成四次命中。
- 无力量/敏捷等伤害公式加成、无暴击和削韧；仍可受到其他装备的出伤修饰与敌人的防御影响，不自动施加燃烧、冰冻或麻痹。
- 激光复用穿透场景，单束对每个目标只命中一次，撞墙消失。
- 升级态低速时增加 `damage_reduction_rate` 0.3，即额外30个百分点减伤；条件解除或卸下后撤销，与已有减伤叠加后由统一伤害链限制范围。
- 暂停时条件采样与周期发射计时都暂停；退出战斗后停止，不在修整期生成激光。

## 复用结构

- `ResolvedObjectSpawnManifestEffect`：按地图特征标签或投射物标签筛选，支持基础/升级概率与可替换的后续 Manifest。
- `EventBus.projectile_resolved`：普通投射物首次命中或物理飞行结束的同步通知，不依赖 `_exit_tree`。
- `DamageData.impact_direction`：保存命中方向；普通投射物已填入，其他攻击未填时保持零向量并走位置方向兜底。
- `ConditionalRelicEffect` 与实体子节点 `ConditionalRelicEffectRunner`：条件判断独立于效果，组合启用其他 `RelicEffect`；支持实际速度和指定面板属性低于阈值。
- AW 的发射由现有 `PeriodicRadialManifestEffect` 负责，减伤由 `AddDerivedStatEffect` 负责，不写进玩家脚本。

## 游戏内测试

1. 用调试器添加并装备巨石精神。先将概率临时设为1方便测试，验证地图岩石击破和消耗品石头两条入口，再恢复0.3/0.5。
2. 设置力量10、无其他出伤修饰：巨石对无护甲敌人造成40点伤害；穿过多个敌人，各命中一次。先给空的巨石 `Sprite2D` 添加贴图，才能直接看到飞行效果。
3. 投出穿透石头命中多个敌人，再到达最远距离：仅首次命中判定。没有命中时，到达最远距离判定。撞墙也只判定一次，墙可能立即挡住新巨石。
4. 存在石头投射物时退出战斗/返回大厅、死亡或切换场景：不能额外生成巨石。卸下后停止触发；装备刷新不重复注册信号。
5. 普通 AW：站立0.5秒后开始发射，速度达到/超过50后停止；低于50重新计时。墙前移动被阻挡时仍能触发，冰面滑行较快时不触发。
6. 升级 AW：低速时属性面板减伤增加30个百分点，快速移动后撤销；卸下后回到原值。无修饰、无防御时，每束激光总伤害4。
7. 暂停游戏数秒：不能出现新激光，恢复后按剩余计时继续。退出战斗后观察修整期，不应残留周期发射。
8. 同时装备射线枪：AW 激光属于正常投射物，可以触发射线枪的追加激光；追加激光本身仍受其递归保护。

## 校验范围

仅执行 Godot 编辑器扫描和静态资源引用检查，不启动游戏。实际命中、视觉和移动阈值按上述步骤测试。
