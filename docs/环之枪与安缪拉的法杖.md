# 环之枪与安缪拉的法杖

## 环之枪
- 穿戴期间敏捷+4、速度+4。
- 只增强由当前玩家召唤的 SummonPet；已有召唤物与之后出现的召唤物都能生效。
- 每只召唤物每秒向80范围内敌人施加1层燃烧；光环不另加直接伤害。
- 升级态实际死亡或寿命到期时，向120范围内敌人造成120点火焰伤害，不暴击、不削韧、无额外属性公式。
- 爆炸来源为穿戴者，不伤玩家、友军及地图物体；卸装、清场、退场不爆炸。
- 基础光环和升级爆炸分别配置，避免升级态重复施加两次燃烧。

## 安缪拉的法杖
- 穿戴期间智力+4、幸运+4。
- 本场首次受到实际正伤害时获得10层护甲，持续至战斗结束。闪避、零伤害和致死伤害不触发。
- 该护甲是受击后获得的，不回头减免首次伤害；装备重建不会重新领取。
- 升级态在战斗开始时出现一个绕角色旋转的盾面：环绕半径36、盾面拦截半径10。不是全方向永久免疫投射物。
- 反弹敌方 ProjectileManifest / AnimatedProjectileManifest 及继承它们的投射物，原方向反转、来源变为玩家、只攻击敌方。
- 保留基础伤害、原施法者一级属性公式快照、速度、穿透及命中状态配置；禁用原追踪和回旋，重新计算可飞行距离，不重新发送发射事件。
- 抛射物、近战特效和地面领域不反弹。独立的粒子弹和 HomingFireflyManifest 不在这两种实体协议内，后续有敌方使用时再接入。
- 反弹目标依然走统一伤害链路，玩家的通用出伤加成及命中效果可正常作用。

## 配置与美术
- 装备资源：`relics/level_6/050_环之枪.tres`、`relics/level_6/051_安缪拉的法杖.tres`。
- 光环：SummonCombatAuraEffect 的半径/周期/状态；死亡爆炸子资源的伤害/半径/类型/视觉场景。
- 护盾：`scenes/ability/manifest/orbiting_projectile_shield.tscn`，Sprite2D 已使用淡青蓝魔法盾贴图，朝右为盾面朝外，随根节点环绕旋转。视觉缩放为0.75、继承最近邻过滤，不改变碰撞判定。若要调整盾面碰撞大小，intercept_radius 与 CircleShape2D.radius 保持一致。
- 爆炸先复用薄圆形扩散脉冲视觉，可以用自己的动画 Manifest 替换。
- 护盾贴图由 Meowa API 生成：`assets/ai art/orbiting_shield/reflecting_shield.png`，32×32 RGBA透明背景。生成需求保存在 `custom_resource/meowa_orbiting_shield_request.json`，使用 object_1 默认配置，十五张候选中选用 output 0。
- 护盾素材任务：`job_bed8b7ba52974e32bc626ce3f14ca683`，本轮独立预算50点，实际生成扣点20点，剩余30点未使用；未沿用其他素材任务的预算。
- 法杖原资源的两个空标签未擅自赋予新类型，仍待作者填写。

## 手动验证
1. 佩戴环之枪后生成多个召唤物，敌人每秒增加燃烧层数；升级后实际死亡及寿命到期各爆炸一次，卸装/退场不爆炸。
2. 普通与升级环之枪均只每秒增加1层，不在装备效果重建后重复附加组件。
3. 法杖首次受伤后状态栏护甲+10，获得临时弹药等导致装备重建后继续受伤也不重复获得；下一场重新允许触发。
4. 升级法杖的盾面碰到普通子弹及动画投射物时，敌方子弹反向飞行并可以命中敌人，不再次命中玩家。
5. 高速弹经过盾面也反弹；墙在盾前面时先撞墙；盾不反弹玩家和友军自己的子弹。
6. 暂停时盾停止环绕、光环停止计时；结束战斗后所有附加组件停止工作。
