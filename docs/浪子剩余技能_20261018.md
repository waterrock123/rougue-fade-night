# 浪子剩余技能实装

## 技能与数值

所有技能均归属浪子（`scount`）。初始技能已加入升级奖励池；升级技能只通过对应分支获得。图鉴、技能树与调试器沿用目录扫描。

| 编号 | 技能 | 效果 |
| --- | --- | --- |
| 124 | 跳弹射击 | 按住瞄准、松开发射；消耗10能量，冷却6秒。首击造成16＋敏捷×0.7远程伤害，在140范围内寻找下一名敌人，最多命中4个不同目标，每跳保留上一跳80%的完整伤害。无需弹药。 |
| 037 | 游击射手 | 连续自主移动1秒后，下次整次基础攻击伤害提高50%。停止移动不会消耗已经准备好的强化，使用后重新积累。 |
| 038 | 游猎本能 | 游击射手的升级；保留普攻强化，使用强化普攻后移动速度额外提高20%，持续2秒，重复触发刷新时间。 |
| 039 | 私藏弹匣 | 装备栏与背包每携带一种不同弹药装备，投射物完整伤害提高5%，最多25%。 |
| 040 | 军火鉴赏家 | 私藏弹匣的升级；投射物伤害上限提高至40%，每种不同弹药额外提供1个百分点暴击率，最多8个百分点。 |

## 判定边界

- 跳弹沿实际飞行路径移动，遵守墙体碰撞和视线判定，不会重复命中同一敌人，也不伤害地图物件。没有合适目标时消失。自动跳弹不会主动选择未激活的中立悬赏怪，直接射中仍可正常触发。
- 每跳衰减包括属性成长，不只是基础伤害；每次弹跳有独立路程预算。施法归属、元素和释放时强化快照沿用现有伤害链路。
- 游击强化按整次普攻消费，多弹普攻不会逐颗扣除。顶墙、纯击退和冰面自然滑行不积累；就绪时有状态图标，战斗结束和卸下被动时清理。
- 弹药按装备ID去重；升级态与未升级态属于同一种，临时弹药也参与统计。非弹药不计数。实际支付弹药后再为本次施法统计，刚消耗掉的最后一种弹药不会继续提供加成。
- 弹药伤害加成要求伤害带有`projectile`标签，不作用于抛射物或普通近战；暴击率是角色属性加成。背包或穿戴变化时自动更新，种类数不变时不重复计算属性。
- 素材复用现有图标、子弹和拖尾，没有使用素材生成API。

## 游戏内验收

1. 使用浪子，在局内调试器按名称添加上述技能；在图鉴查看两个被动的升级关系。
2. 将三至四名敌人放在相距140以内的位置，释放跳弹射击，确认转向、最多四名不同目标和逐次伤害衰减；在两名敌人之间设置墙，确认不会穿墙弹跳。
3. 携带游击射手，连续移动1秒，观察就绪状态。停止后普攻应仍强化，第二次普攻不强化；不足1秒时停止则重新积累。游猎本能额外检查短暂移速状态及其到期恢复。
4. 携带私藏弹匣或军火鉴赏家，先放入同ID的普通、升级或临时弹药，再加入其他ID弹药，确认只有不同种类增加收益。军火鉴赏家的暴击率可以在属性面板核对。
5. 消耗、出售或移除最后一件某种弹药，确认加成同步下降；背包与装备栏互换但种类数不变时收益不变。
