# 紫晶戒指与魂火

## 首版规则
- 成功释放非基础主动技能后，20%概率召唤一只魂火；失败施法、预瞄准和基础攻击不触发。
- 每件戒指最多同时存活3只，魂火存活30秒，40点生命，沿用攻击型召唤物的追敌/回归 AI。
- 每秒对80范围内敌人造成30点火焰伤害，加上召唤时主人智力的50%，并施加1层灼烧。脉冲不暴击、不削韧，不攻击地图物件。
- 升级态：魂火实际死亡或到期时，主人随机一级属性本局永久+1；卸装、玩家死亡、战斗结束和切场景清理不奖励。
- 普通装备效果重建不会重复订阅施法事件，也不会重置现有魂火的寿命。

## 配置入口
- 装备：`relics/level_5/048_紫晶戒指.tres`，CastSummon 子资源可修改概率、数量、寿命、快照属性以及死亡奖励。
- 召唤物：`entity/summon_pet/soul_fire_summon_pet.tscn`，可修改生命和移动速度。
- 脉冲：`scenes/ability/soul_fire_pulse.tscn`，复用目标搜索、直接伤害、施加状态和视觉生成组件。
- 寿命组件只负责到期死亡；SoulFirePet 只补充漂浮与淡出；RadialPulseVisualManifest 只负责视觉。
- 替换其他召唤场景时，bonus_damage_ratio 会增加该场景所有 AbilityDealDamage 的基础伤害；场景自身属性公式仍会执行，注意避免重复计算。

## 手动测试
1. 装备紫晶戒指，可临时把 summon_chance 调为1方便验证；基础攻击不召唤，其他成功施法召唤，最多3只。
2. 检查魂火每秒范围伤害及灼烧，主人智力改变后已有魂火伤害不变，新魂火使用新快照。
3. 升级戒指后等待30秒或让敌人击杀魂火，随机属性只提升一次；卸装/结束战斗/退场不提升。
4. 战斗期间刷新装备效果（如获得临时弹药）不重复召唤、不清理已有魂火。
5. 在墙边施法，魂火应只落在可达区域；暂停游戏时寿命和脉冲均暂停。
