# 训练场

从大厅训练场入口进入，使用大厅当前角色。训练构筑每次重新创建，不应用局外信物，不写正式单局存档。

- 假人暂借现有骷髅外观，不移动或攻击，保留受击、状态和破韧反馈。击倒一秒后重新生成。
- 顶部可修改假人生命、固定减伤与韧性，点击“应用并重置假人”生效。
- 无限生命默认开启（使用无敌保护），无限能量默认开启，无冷却默认关闭。“无冷却”实际将施法冷却设为 0.1 秒，避免每帧释放导致音效和特效过度堆叠；不会跳过技能动画、引导和弹药要求。
- 假人驻点在进入训练场时确定，死亡复活与手动重置不会跟随玩家移动。
- 通过调试台添加装备与技能，再通过背包操作装备。主动、被动技能仍遵循当前构筑数量上限。
- “重置训练”会清空本次测试构筑并重新进入。关闭无限生命后死亡也重新进入。
- 返回大厅按钮或 Esc 离开。调试台打开时先关闭调试台。

## 手动验证

1. 保留一个正式继续存档，从大厅使用不同角色进入训练场，确认角色、初始技能一致。
2. 攻击假人，验证伤害、状态、破韧及死亡后重新生成。
3. 分别切换无限能量和无冷却，验证技能消耗与冷却图标。
4. 调试台授予装备、主动和被动技能，通过背包装备后验证效果。
5. 返回大厅继续正式存档，确认训练所得装备与技能没有进入正式构筑。

本轮仅做编辑器扫描，以上实际交互需要在游戏中验证。假人外观可以在 training_dummy 场景中替换已有精灵动画。
