# 战狂：跃地重斩、铁壁反击与破阵者

## 技能内容

全部为战狂专属，角色归属键为`warrior`。新增初始技能已加入升级奖励池；两个被动升级分支不直接随机，只替换破阵者。图鉴、技能树和调试器自动扫描这些资源。

| 编号 | 技能 | 效果 |
| --- | --- | --- |
| 125 | 跃地重斩 | 12能量，8秒冷却。按住选择落点，松开跃进，最大距离180；0.4秒落地，对75范围内敌人造成30＋力量×1.5近战伤害，削韧36。 |
| 126 | 铁壁反击 | 10能量，7秒冷却。朝施放时鼠标方向防御0.8秒，正面180度攻击减伤60%，移动速度降低50%。前0.25秒精准格挡使该次伤害降低90%，随后向前方85距离、120度扇形反击，造成25＋力量×1.2近战伤害、削韧40，并恢复5能量。 |
| 041 | 破阵者 | 本人使敌人破韧后，下一次整次基础攻击伤害提高40%，最多保留5秒。不叠加，再次破韧刷新时间。 |
| 042 | 摧枯拉朽 | 破阵者升级分支。普攻强化提高至70%；强化普攻首次有效命中时，对该目标75范围内其他敌人造成力量×1近战伤害，每次普攻最多溅射一次。 |
| 043 | 乘隙猛攻 | 破阵者升级分支。保留40%普攻强化；本人破韧额外使所有非基础主动技能剩余冷却减少1秒，每2秒最多触发一次减冷却。 |

## 边界与交互

- 跃进不是瞬移或无敌：实体沿安全路线物理移动，贴图与武器做抛物线升降，不跨墙、不落在地图外。途中出现障碍时提前在当前位置落地；控制、死亡、战斗结束或移除技能则取消后续伤害，并还原视觉位置。
- 跳跃期间不能释放其他技能；铁壁防御期间可以减速移动，但不能释放其他技能。完成或取消时只撤销自己的施法锁，不影响其他控制来源。
- 铁壁锁定完整二维方向，不局限左右朝向。弧线亮金色为精准窗口，随后转为淡白色；状态图标显示防御持续时间。
- 格挡发生在闪避、属性攻防结算之后、扣血之前，真实减少生命损失，并非受伤后回血。闪避、无敌和已经减至0的伤害不会触发精准反击。
- 防御不免疫控制，不防背面、状态持续伤害、地形伤害、自伤或反伤。反击延后到下一处理帧，每次最多一次；同帧的后续正面攻击只获得普通格挡减伤。
- 精准反击提前结束防御；若受控制、死亡或离场打断，取消待反击与能量返还。没有精准格挡时到期收招，不自动攻击。
- 跃地落地伤害、铁壁反击与摧枯拉朽溅射均不伤害地图物件，范围查询遵守墙体视线。
- 破阵者只接收本人对敌人的破韧事件，不接受友军破韧、地图物件或禁止技能联动的次级伤害。普攻强化按整次施法消费，非普攻不消耗。
- 摧枯拉朽的溅射不命中原目标，不继承本次普攻的70%强化，也不削韧；它走统一伤害入口，但关闭技能递归联动。
- 强化在5秒内释放的普攻会保存伤害快照，之后命中仍有效。战斗结束或卸下被动时清理等待中的强化和监听器。

## 可复用组件

- `AbilityLeapToCursor`：只负责安全跃进、贴图升降、锁定与落地子链；距离、时间、高度、视觉节点路径可配置，继承现有安全落点解析。
- `AbilityDirectionalGuard`：只负责方向防御、精准窗口、减速与反击子链；不把伤害公式写死在组件内。
- `PassivePoiseBreakBasicAttackEffect`与独立监听器：只负责破韧事件、限时整次普攻强化、可选溅射和限频减冷却。
- `Entity.damage_receive_prepared`：统一扣血前同步拦截信号，未连接监听器时不改变旧伤害行为。
- `AbilityGetCombatTargets.require_line_of_sight`：新增可选视线过滤，默认关闭，不改变旧场景行为。

## 美术与配置

本轮没有调用素材API。跃地暂时复用已有震荡波动画；反击复用已有斩击贴图，但使用独立的纯视觉Manifest，不重新读取鼠标、不隐藏角色武器。专用跳跃或格挡逐帧动画没有创建。

可在以下场景调整参数与表现：

- `scenes/ability/warrior_leap_slam_ability.tscn`：`Indicator`调整预览；`Leap`调整距离、时长和高度；`Leap/LandingVisual`替换落地动画；`Leap/Damage`调整伤害、成长及削韧。修改距离或范围时同步更新Indicator。
- `scenes/ability/warrior_iron_counter_ability.tscn`：`Guard`调整防御参数；`Guard/Targets`调整反击扇形；`Guard/Damage`调整伤害与削韧；`Guard/CounterVisual`替换反击动画。
- `passive_skill/041_formation_breaker.tres`至`043_seize_the_breach.tres`：调整对应效果资源中的强化比例、保留时间、溅射范围和减冷却间隔。

## 游戏内验收

1. 使用战狂，在局内调试器按名称添加两个主动与破阵者。检查图鉴及技能树中两个升级分支与破阵者正确连接。
2. 按住跃地重斩，确认最大180大圆与75落点小圆；朝空地、墙角、边界分别释放，确认不会穿墙或落到场外，落地后恢复移动。跳跃中受控或退出战斗，不应再补发伤害或留下悬空贴图。
3. 朝上下左右分别释放铁壁反击，让敌人从正面和背面攻击。比较普通窗口与精准窗口的生命损失；精准成功应只反击一次、恢复5能量，结束后移动速度恢复。
4. 站在伤害地形中防御，不应触发精准反击或减免该持续伤害。被控制打断后不应继续反击。
5. 攻击使敌人进入韧性状态后将其破韧，观察就绪状态；非基础技能不消费，下一次普攻消费，等待超过5秒则失效。
6. 升级为摧枯拉朽，测试一个强化普攻命中多名敌人时只溅射一次；升级为乘隙猛攻，先使两个主动进入冷却，再同时破韧多名敌人，确认只各减少1秒，2秒后才能再次削减。

## 校验方式

只执行Godot编辑器扫描与隔离真实函数检查，不启动主场景或战斗，不修改玩家存档。新检查脚本为`scripts/utils/warrior_combat_skills_editor_check.gd`，日志为`.godot/warrior_skills_check.log`。编辑器退出时仍可能出现项目已有的UID后备路径及资源清理提示，需与脚本解析或用例失败分别看待；完整战斗手感由游戏内验收确认。
