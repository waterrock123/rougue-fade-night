# 张三 NPC：我的超能力是杂活

## 已接入的流程

1. 地图随机事件池已加入 `event_room/confused_man_room.tscn`（迷茫之人）。
2. 选择主动技能或三阶及以上装备后结束抉择；追问超能力会切换为邀请选项。三个分支互斥。
3. 邀请立即记入局外档案；张三在下次进入大厅时出现，重复遇见不能再次邀请。
4. 第一次完整交谈记录设施请求。玩家从大厅仓库选定一件携带，然后点击“交付携带的设施”。
5. 冰箱（081）、水桶（002）、太阳能发电板（106）各交一件，可分次完成。升级态也接受，锁定装备不接受，已交物品不会重复扣除。
6. 三件齐备后显示大厅的 `ImprovedFacilities` 容器，并开放“收获心情”。首次点击播放功能说明，听完后离开才记录说明完成。
7. 解锁设施后，每次整局死亡或最终通关增加一次领取机会。中途回大厅、继续游戏、单场战斗胜利、训练场均不增加。
8. 奖励进入局外仓库；仓库满或未解锁时不扣次数。次数可跨局积累。交付/领取保存失败时回滚物品与计数。
9. 招募、请求、设施完成、心情说明四条记录均加入图鉴事件数据库。

## 奖励配置

`resource/profile/zhang_san_mood_pool.tres` 是显式的正面心情白名单，不依据装备名称猜测正负面。
目前仅放入已有实际效果的“自然的喜悦”（207）。
“改变的欣喜”（209）和“胸有成竹的自信”（210）目前尚未配置效果，先不作为可领取奖励；补齐后可以加入此池。
池内装备原图标仍由现有装备资源决定，不会自动生成或借用其他美术。

## 需要补充的美术

- `resource/hub_npc/zhang_san_visual_data.tres`：已接入网站生成的扫地工待机动画，默认动画名 `idle`。每帧 32×32，沿用通用 NPC 的最近邻过滤。
- `resource/hub_npc/zhang_san_interaction.tres`：可选填写对话头像。
- `scenes/hub/main_home_map.tscn`：`NpcContainer/ZhangSanMarker` 为驻点，可自行调整位置；在 `ImprovedFacilities` 下放置冰箱等装饰，脚本负责统一显隐。不要把有碰撞的装饰当成纯显隐装饰，隐藏不会关闭其物理碰撞。
- `event_room/confused_man_room.tscn`：`Background` 贴图留空。

## 手动测试

1. 在局内调试器把下个事件设为 `ConfusedManRoom [confused_man_room]`，进入房间测试三个分支；主动技能遵守角色归属、未持有、非升级分支和持有上限。
2. 邀请后回大厅，去张三驻点交谈；提前退出首段对白不应记录设施请求。
3. 分别携带三种设施交付；测试锁定、非请求物品、重复设施；重启后交付清单应保持。
4. 三种齐备后点击心情功能并读完说明。刚解锁而尚未结束整局时不应直接获得奖励。
5. 解锁后整局死亡一次，再回大厅领取；随后再次领取应提示无次数。最终通关同样增加一次。
6. 仓库满时领取，次数应保留；腾出空间后可成功领取。中途退回/续档不应增加次数。
7. 查看图鉴事件记录与设施装饰显隐。
