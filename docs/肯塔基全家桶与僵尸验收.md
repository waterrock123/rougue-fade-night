# 肯塔基全家桶与僵尸

## 装备规则

- 五阶消耗品，编号129；保留原名称、价格、标签与简介。
- 使用后通过统一治疗入口恢复全部已损生命，刷新当前全部主动技能的剩余冷却（包括基础攻击与装备技能），不改变后续基础冷却。
- 周围生成两只僵尸，出生目标距离72；使用地图安全落点接口避开墙外、封闭区域和相互重叠。整个生成延迟执行，避免物理碰撞回调中新增实体报错。
- 升级态额外获得“全家桶增益”正向状态：力量、体质各+5，持续至本场战斗结束，可在状态栏查看。不是直接写入局内永久基础属性；沿用现有临时属性策略，狼奶等机制仍可作用。
- 装备消耗、保留概率与原料相关事件仍走现有消耗品使用流程。

## 僵尸首版

继承Enemy的通用无阵营实体 `FreeForAllEnemy`，不是玩家召唤物。

- 80生命、移动速度45；每1.6秒可发动普通攻击，零能量消耗。
- 普通攻击：面向当前目标，原地播放1秒挥击动画，在第5帧（索引4，约0.5秒）对前方110度、42距离内的战斗实体造成12基础物理伤害，不暴击，8点削韧。默认属性公式依旧可用，当前僵尸力量为0。
- 攻击目标包含玩家、友军召唤物、敌人、其他僵尸；排除自己和地图物件。目标刷新间隔0.25秒，不每帧重复全图搜索。
- 普通敌人会主动追击僵尸，敌人的通用近战搜索、投射物也可以命中；不把僵尸伪装成玩家或友军，所以僵尸杀敌不会因阵营判定自动视作玩家击杀。
- 不加入波次必杀名单，也不登记为悬赏怪，因此不会阻止战斗胜利，也不会弹出悬赏怪提示。
- 死亡时播放非循环倒地动画，结束后释放；胜利结算、失败、切场景时清理，不保存到下一场战斗。

## 手动验收

1. 调试台添加全家桶并装备。受到伤害、释放有冷却的技能后按消耗品按键，确认生命回满、冷却归零、出现两只僵尸，普通态无额外属性增益。
2. 使用升级态，确认状态栏出现全家桶增益，力量与体质各+5；进入下一场不保留该临时状态。若有狼奶等转化机制，按其原规则结算。
3. 走近僵尸，确认它会攻击玩家；让敌人、友军或另一只僵尸更近，确认目标可切换；苹果树等地图物件不受僵尸挥击影响。
4. 测试敌人的近战和投射物能击中僵尸，玩家也能击中；击杀后倒地动画结束，节点被释放。
5. 在地图边缘、狭窄走廊使用，检查安全落点与两个实体间距；若附近没有足够安全空间，跳过无法安放的实体，不生成到场外。
6. 留下僵尸、清空正常波次怪物，确认仍然正常进入升级奖励；胜利、死亡或退出游戏不残留僵尸。
7. 暂停时不继续移动、播放动画或造成命中伤害。正在挥击的僵尸被击杀/冻结/硬直打断后，旧命中上下文应失效。
