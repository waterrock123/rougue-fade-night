# 大厅 NPC 对话阶段

在 NPC 的交互资源中配置 `dialogue_stages`，按数组顺序选择第一个满足条件的阶段。未配置阶段的旧 NPC 继续使用原有对白。

- `required_event_ids`：必须全部完成的局外事件。
- `excluded_event_ids`：其中任一事件已完成时跳过本阶段。
- `completion_event_id`：完整展示对白后离开或选择功能时记录的事件，需登记到事件数据库。
- `repeatable`：允许重复交谈；一次性阶段必须填写完成事件。
- `random_line`：日常闲聊随机取一句，剧情关闭此项以逐句播放。
- `actions`：本阶段的功能按钮，空数组表示仅交谈。

## 古董店女店员样例

认识迷途记录员后可见。初见赠送信物，之后进入日常闲聊；首次通关后再次交谈，讲述旧徽章的故事；完成故事后使用熟客对白。旧徽章后续剧情没有额外数值奖励。

阶段保存在 `resource/hub_npc/antique_clerk_interaction.tres` 的子资源中，可以在检查器展开修改。美术与头像沿用 NPC 原有配置。

## 测试顺序

1. 初见时提前离开，不应获得奖励，下次交谈仍从初见开始。
2. 完整阅读初见对白后离开，图鉴收录且解锁信物；再次交谈出现日常对白。
3. 通关一次后回来交谈，应触发旧徽章故事；提前离开可重新阅读。
4. 完成故事后，图鉴增加对应记录，再次交谈为熟客闲聊，不重复奖励。
5. 重启游戏后阶段保持。更新前的历史通关未记录首次凯旋，需要更新后通关一次。
