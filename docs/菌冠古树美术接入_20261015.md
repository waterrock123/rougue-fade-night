# 菌冠古树动画美术

## 规格与生成方式

- 使用项目现有 Meowa API 工具，而非替换其他图片服务。
- 大型怪物模板，128×128 RGBA 造型；首轮动作有根须触碰边缘，最终增加透明边距后生成 192×192 动画画布。
- 蘑菇层冠、棕色古树、根须双臂、琥珀眼睛；正面略俯视，匹配驻扎型 Boss。
- 最终动画统一使用 `assets/enemy/mushroom_tree_boss/animation_reference.png`，仅为原始造型增加透明边距，不重绘或缩放角色。
- 完整提示词和动作时间线保存在 `custom_resource/meowa_mushroom_tree_boss_*_20261015.json`。
- 不逐帧裁切、不混用多个造型候选；原始 WebP、图集与每帧时长均保留。正式素材在同目录的 `padded/` 中，首轮保留作备选。
- 2026-10-16 已接入 `entity/enemy/mushroom_tree_boss.tscn`，SpriteFrames 为 `sprite_frames/mushroom_tree_boss_sprite_frames.tres`。
- 精灵显示缩放 1.6、位置 `(0,-96)`，最近邻过滤；血条上移到头顶，伤害数字高度 192。根节点缩放、身体半径 30、受击半径 48 均不变。

## 动作对应

| 动作 | 用途 | 播放方式 |
| --- | --- | --- |
| idle | 树冠微动、呼吸与眼睛发光 | 2 秒循环 |
| attack | 根须横扫 | 适配 1.8 秒出招流程，不循环 |
| cast | 孢子播撒、菌环脉冲共用 | 2 秒，不循环 |
| relocate | 收拢树根、下沉、重新展开 | 2 秒，不循环；真正的瞬移和淡出仍由原组件处理 |
| die | 树冠垂落、根须塌下 | 2 秒，不循环；播完沿用敌人死亡释放逻辑 |

动画只负责表现，横扫、孢子落地和菌环伤害仍由原有组件的时间轴结算。
二阶段的第二圈脉冲沿用原技能流程，不需要靠循环施法动画制造第二次伤害。

## 导入工具

`import_meowa_sprite_frames.gd` 新增可选的第三个参数：逗号分隔的动画名称。
省略时仍按 `idle,walk,attack,die` 导入，不影响冰原小怪的既有流程。
元数据可填写 `playback_duration_seconds`，只改变播放速度，不复制、删除或重绘帧。

```powershell
& 'E:\Godot_v4.6.2-stable_mono_win64\Godot_v4.6.2-stable_mono_win64_console.exe' --headless --path . --editor --script res://scripts/utils/import_meowa_sprite_frames.gd -- res://assets/enemy/mushroom_tree_boss/padded res://sprite_frames/mushroom_tree_boss_sprite_frames.tres 'idle,attack,cast,relocate,die'
```
