# 贵人基础攻击

## 使用与配置

- 新开一局选择贵人，起始技能会自动加入基础攻击栏；不自动修改已有存档的技能列表。
- 技能数据：`activate_skill/112_basic_guiren_attack.tres`，id=112，仅归属 wizard。
- 技能场景：`scenes/ability/guiren_basic_attack_ability.tscn`。
- 飞弹场景：`scenes/ability/manifest/guiren_magic_missile_manifest.tscn`。
- 冷却 0.5 秒，能量消耗 3，每次同时发射三枚，每枚基础伤害 3，不额外增加敏捷或智力公式。
- 暂用现有远程伤害类型与 magic 标签，不引入新的魔法伤害体系；暴击、装备增伤、闪避和减伤仍走统一伤害链路。

## 组件分工

1. `AbilityLockNearestTargetDirection`：在角色周围 600 范围选择最近的有效敌人，并锁定初始朝向。
2. `AbilityAnimationRunner`：播放贵人的 attack。原始美术帧不变，播放时长调整为 0.5 秒匹配普攻冷却。
3. `AbilitySpawnManifestVolley`：固定同时生成三枚，横向错开并略微展开，不启用浪子的累计奖励子弹。
4. `ProjectileManifest` 与 `ProjectileHomingController`：各自追踪附近最近的有效敌人；目标消失后重新索敌。
5. `ProjectileTrail2D`：复用现有紫色飞弹贴图与拖尾，不额外生成美术。

追踪速度为 12 弧度/秒，弹速 240，最大飞行路程 600；不穿透，命中或撞墙消失。
没有敌人时仍可朝鼠标方向空放，鼠标与角色重合时回退角色朝向。
自动索敌不选择未激活的中立悬赏怪，与原追踪投射物规则一致；已激活后正常选择。
每枚飞弹独立结算一次伤害及 2 点削韧，来源技能 id 和基础攻击槽位沿用现有事件机制。

## 检查

`scripts/utils/guiren_basic_attack_editor_check.gd` 进行编辑器资源载入、脚本解析和实际函数的隔离测试。
涵盖最近敌人在身后、无目标、死亡/中立/不可选中目标、目标释放后的重选、连续多次固定三发以及齐射上下文还原。
不启动战斗、不读写存档。实战请检查三弹是否可见、追踪移动敌人、命中和撞墙销毁，以及按住基础攻击键的连续释放。

本次回归结果：普攻资源与隔离测试 53 项、贵人动画回归 40 项，全部通过；包含流星五发与移除修正后恢复三发。
编辑器退出仍有既有石头投射物 UID 和 RID/ObjectDB 清理日志，本次未处理这些独立问题。
