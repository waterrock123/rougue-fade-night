# 西瓜与冰镇西瓜

## 已确认规则

- 西瓜使用后恢复 20 生命和 20 能量，仍是一次性消耗品。
- 升级西瓜使用后，所有技能（包含基础攻击）冷却减少 20%。持续时间未指定，按前面建议先设 20 秒，可修改 status/watermelon_cooldown.tres 的 duration。
- 只有西瓜自身 tags 获得寒霜标签才转换，不因玩家持有其他寒霜装备而转换。背包和装备栏均可触发。
- 转换保留升级态、临时标记和装备已积累的属性。目标名称、等阶、价格和原始标签采用冰镇西瓜资源。
- 转换本身不是合成或新获得，不奖励免费三选一；未新增自动合成入口。
- 冰镇西瓜使用后恢复 25 生命和 30 能量，20 秒内主动技能冷却减半，不包含基础攻击。
- 升级冰镇西瓜额外提供 60 秒冰霜附魔：基础攻击命中追加一个 5 点基础 ICE 伤害包，不额外暴击或削韧，不自动施加冰冻。
- 附加冰伤仍经过统一伤害、减伤和闪避流程；属性或其他伤害修正可能使最终飘字不等于 5。
- 冷却修正沿用现有系统，影响之后施放技能的冷却，不直接削减已经在倒计时的剩余冷却。
- 相同状态再次使用刷新持续时间，不叠加倍率或附魔伤害；离开战斗或到期清理。
- 新存档保存装备实际标签，兼容旧存档使用资源原始标签。

## 实现复用

- 治疗与能量恢复复用 UseHealEffect、UseRestoreEnergyEffect。
- 限时增益复用 UseAddStatusEffect 和 StatusAbilityCooldownEffect；新增 excluded_slot_indices 通用排除筛选。
- SelfTagTransformRelicEffect 按自身标签转换资源，路径加载避免资源循环引用；修改 required_tag 与 result_relic_path 即可复用。
- StatusOutgoingExtraDamageEffect 提供按技能栏位追加指定类型伤害的临时状态效果，默认筛选基础攻击。
- 新增 {ice} 关键词用于解释冰伤，不等同于 {freeze} 冰冻状态。

## 人工测试

1. 玩家受伤并消耗能量后装备西瓜，使用后检查恢复 20/20 且道具消失。
2. 使用升级西瓜，检查“消暑”状态持续 20 秒，基础攻击与其他技能随后施放的冷却均变为 80%。
3. 在背包中放入西瓜，给另一件装备寒霜标签，确认西瓜不转换。
4. 给西瓜自身添加现有寒霜标签，并发送 inventory_update；检查原格子变为冰镇西瓜。
5. 对装备栏重复步骤 4，发送 equipment_update，检查格子与消耗品 UI 更新；升级西瓜应转换为升级冰镇西瓜。
6. 可使用已有“战斗结束给原料添加寒霜标签”的效果测试真实事件链；若事件随机选择其他原料，可先移走它们。
7. 使用冰镇西瓜，检查恢复 25/30、20 秒状态、基础攻击冷却不变，其他主动技能冷却减半。
8. 使用升级冰镇西瓜攻击存活敌人，检查附加冰伤与 60 秒状态；追加伤害不得递归产生无限伤害。
9. 重复使用冰镇西瓜，确认状态刷新而非伤害与倍率叠加；状态到期后附加冰伤消失。
10. 转换后于合法检查点退出并继续，检查装备 id=135 且升级态保留。

仅做编辑器扫描校验，不自动启动游戏；实际游玩需按上述步骤测试。
