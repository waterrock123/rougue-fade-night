# 狼奶与轮回肠

## 当前规则

- 狼奶（121，五阶消耗品）：使用后，本场战斗中新获得的正向临时一级/派生属性增量保留至战斗结束；原有增益、负面效果、装备和被动常驻修饰不转换。
- 升级狼奶：以上新增增量写入 PlayerBuild.permanent_stat_bonuses，本局跨战斗保留，参与已有保存检查点；不是局外永久加成。不会把先前普通狼奶保留的加成再转为永久。
- 狼奶仅延长属性增量，不改变原状态的控制、伤害、视觉效果或共享 StatusData.duration。原增益图标到期消失后，保留的属性仍存在；狼奶策略自身保留在状态列表。
- 轮回肠（122，五阶消耗品）：暂按“恢复本次开局基础快照，清除本局基础属性成长和狼奶永久账本，并清除临时属性增减”实现。装备/被动常驻修饰、技能、背包不删除。并非把最终面板硬锁为裸装属性。
- 重置保留本次开局已应用的局外奖励和高阶携带惩罚。不主动治疗或恢复能量，当前生命/能量保留实际数值并夹取到新上限。
- 升级轮回肠：额外清空全部技能当前冷却，之后10秒内将基础攻击、普通主动、装备额外主动冷却固定为0.01秒。能量、弹药、施法锁和控制状态规则仍生效；长持续技能不因此提前结束。
- 轮回肠不清空 RunStats 单独保存的套装状态/技能进度。如果希望连这些也归零，需要单独明确重置范围。
- 两件装备原本没有图标，本次未生成或绑定美术素材。

## 实现入口

- TemporaryStatGainPolicy：按来源跟踪增量，独立保留战斗收益与本局永久收益，不把刷新当作重新获取。
- StatsController.set_temporary_effect_modifiers：战斗中/消耗品的新属性增减入口。常驻装备与被动继续使用 set_effect_modifiers。
- StatusController.add_status 最后一个可选参数 attribute_gain_eligible：战斗获得的来源默认 true；装备/被动常驻、已由 RunStats 永久记录的来源使用 false。同id混合来源按有效层数区分。
- StatusTemporaryStatGainPolicyEffect：仅启用增益转换策略，模式可选 BATTLE/PERMANENT。
- UseResetBaseStatsEffect：仅负责基础/临时属性重置；clear_temporary_stats 可以关闭临时增减清理，保留只重置基础成长的行为。
- StatusAbilityCooldownEffect：cooldown_override=-1 时保留旧修正规则；非负值固定冷却；reset_current_cooldowns 控制施加时是否清空等待中的冷却。
- 新存档保存 initial_stats 和 permanent_stat_bonuses。旧档缺少开局快照时使用角色初始资源并恢复携带惩罚，无法精确重建当时未记录的局外开局奖励；建议新开一局验收轮回肠。

## 手动验收

1. 调试器添加普通狼奶，装备并在战斗中使用；先获得一个短时增益再用狼奶，确认旧增益仍正常到期；使用后再获得同类新增益，确认新增部分到期后仍计入属性。
2. 佩戴提供护甲的装备，再使用狼奶、触发新的护甲状态；检查只有新增战斗层数转换，常驻装备护甲没有被复制。刷新相同层数的状态不应反复增加属性。
3. 使用升级狼奶，再使用牛奶/鸡蛋等属性消耗品或触发嗜血，确认正值计入面板，负值不转换；下一场战斗仍有永久正值，普通狼奶收益则消失。
4. 到已有的战斗胜利保存检查点后退出再继续，确认升级狼奶的永久值仍在。战斗中途退出仍遵循项目已有的检查点回滚，并非实时保存每次使用。
5. 获得一些本局基础属性成长和临时增减，使用普通轮回肠；确认基础成长归零、装备与被动仍生效；当前生命和能量不凭空回满。
6. 临时累积型效果已有加成时使用轮回肠，之后再次触发该效果，只恢复新增的那一份，不应把旧累计值整体加回来。
7. 将若干技能置于冷却，再使用升级轮回肠；确认立即可施放，之后10秒内固定0.01秒（受游戏帧率限制，不等于每秒实际可触发100次）；10秒后新的施放恢复原冷却。不足能量/弹药时仍不得释放。
