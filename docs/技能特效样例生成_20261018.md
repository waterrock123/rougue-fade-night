# 技能特效样例生成

## 授权范围

- 本轮新预算上限100点，分批检查，不沿用历史任务余额。
- 首轮仅冰晶爆发、魔法符文底图、精准格挡火花三类样例，不扩展全部技能。
- 先生成造型候选，检查后选择；动画逐段报价，未知价格或可能超出余额时停止。
- 只使用Meowa现有开发期工具，不运行游戏场景；网络结果不明时先查任务记录，不重复收费提交。

## 素材策略

首批使用已验证过的object_1默认模板生成候选。模板输出32像素造型，不将其冒称96像素原生动画。冰晶和火花若需要扩散空间，将保留原始像素并增加透明画布，再制作独立帧动画；符文优先作为静态透明底图，由Shader控制显隐和微弱脉冲。

现有Frost Knight素材包已检查VFX1和VFX2：主要是带武器的定向斩击，不直接替代圆形冰晶爆发。原素材保持不变。

## 验收

1. 检查透明背景、轮廓清晰、没有角色或场景、没有边缘裁切。
2. 冰晶必须向四周扩散，而不是单向剑气；符文中央不能是遮挡角色的实心圆盘；火花应短促，不是一颗常驻星星。
3. 动画保留固定画布、中心和时长；不逐帧重新裁切。生成原始文件与游戏图集分开保存。
4. 只为通过验收的结果接入纯视觉节点，不更改技能伤害、冻结时长、格挡窗口或命中判定。

## 接入结果

- 寒星环：使用冰晶爆发动画，原始2秒动画以0.28秒播放，适配原有0.3秒视觉尾声；范围100、伤害和冻结时长保持原样。正式动画外保留准确范围细边线，关闭实心圆填充。
- 雷电法阵：使用32×32镂空符文底图，独立表现组件根据真实伤害脉冲提亮，并在原有尾声淡出。保持四次伤害、首次1秒的时序。符文中央8×8区域有42个全透明像素，中心像素及画布角落透明，不是实心圆盘。
- 铁壁反击：精准成功后的反击子链在正前方28距离生成火花，0.22秒播完释放，不改精准窗口、反击伤害或施法限制。普通格挡不播放精准火花。

素材目录：`assets/特效/skill_vfx_samples_20261018/`。保留原始参考图、API动画WebP、无损拆帧PNG、原始时长元数据和预览；游戏使用`sprite_frames/skill_vfx_samples_20261018.tres`。原始动画不逐帧重裁，不把候选图当连续动画。

冰晶可见像素最大半径34.50，火花24.51，所有帧均无可见像素触边，两段末帧完全透明。原始动画时长均为2秒，运行时仅调整播放速度，没有修改原始数据。

## 提示词与可复用代码

候选提示词完整保存在`custom_resource/meowa_skill_vfx_sources_20261018.json`，动画时间线在`meowa_skill_frost_burst_20261018.json`与`meowa_skill_guard_spark_20261018.json`。核心约束是独立透明背景、固定中心和画布、硬边像素、单次向外扩散消散、没有角色或场景；冰晶用淡蓝白、火花用金白，符文采用镂空几何环。

`RadialSkillVisual`只读取父级范围技能的半径、计时和脉冲计数，不参与伤害。`AnimatedAbilityManifest.playback_seconds`默认为0，旧场景保留原始时长。新的像素表现Shader不模糊贴图、不膨胀命中范围，使用顶点颜色保留淡出且避免重复采样颜色相乘。

仅执行编辑器扫描与隔离检查，不自动启动游戏；检查脚本为`scripts/utils/skill_vfx_samples_editor_check.gd`，日志位于`.godot/skill_vfx_samples_check.log`。编辑器退出可能继续输出原有UID后备路径和RID/ObjectDB清理提示。
