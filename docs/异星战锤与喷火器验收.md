# 异星战锤与喷火器

## 异星战锤
- 普通态：力量+5、削韧倍率+50%。持有者亲自使敌人破韧时获得一层“破韧之力”，每层力量+1，持续至战斗结束，不改 PlayerBuild 的永久一级属性。
- 升级态：被破韧的敌人额外受到当前力量500%的物理近战伤害。先获得此次力量层数，再取当前力量计算；不再额外附加默认物理力量公式，不暴击、不削韧，防止破韧递归。
- 基础加成卸下会撤销；已经获得的战斗内状态保留至战斗结束。装备效果重建不会清空已有状态。
- 扩展通用 PoiseBreakDamageEffect 的 source_stat/stat_multiplier；原铁牙签等默认固定伤害不变。
- 原资源未填的 id 补为141，价格先按五阶设为5；图标仍待补充。

## 喷火器
- 装备后由 GrantActiveSkillEffect 提供额外技能“喷射火焰”，不占普通技能携带上限；卸下时移除对应临时来源。
- 按下对应技能键开启，持续5秒跟随角色与鼠标方向喷射。距离120、扇形完整夹角40°，每0.2秒查询一次真实碰撞区域，命中敌人造成10点火焰伤害并附加1层燃烧。
- 火焰不使用属性伤害公式、默认不暴击、不削韧；照常走统一出伤、减伤和闪避链路。燃烧沿用现有8秒状态，每次叠层刷新持续时间。
- 施法时移动速度减半，只禁止基础攻击和再次开启本技能，其他主动技能照常使用。限制状态结束或施法中断后撤销。
- 冷却/能量未指定，首版暂定10秒/10点，只在开启时消耗；在 `activate_skill/111_flamethrower.tres` 配置。
- 升级态提供所有火焰伤害+2，火焰喷射直接跳伤也会读取这一出伤加成。
- 受控制、死亡、战斗结束或实际失去该技能时停止喷射。技能栏重建但仍拥有同id技能时不中断；不会通过旧 Ability 对象继续访问已释放节点。
- 范围查询排除友军、地图物件与重复受击区；每个目标独立检查World碰撞层，避免隔墙命中。

## 可配置位置
- 装备：`relics/level_5/141_异星战锤.tres`、`relics/level_4/136_喷火器.tres`。
- 技能：`activate_skill/111_flamethrower.tres`、`scenes/ability/flamethrower_ability.tscn`，未放入升级奖励池。
- 火焰实体：`scenes/ability/manifest/flamethrower_stream_manifest.tscn`。lifetime、max_range、angle_degrees、tick_interval、damage、hit_status 都可配置。
- 施法限制：`status/flame_channel.tres`；局部禁用脚本为 StatusBlockAbilitiesEffect，可供其他持续技能复用。
- 破韧力量：`status/poise_break_strength.tres`。
- 火焰粒子复用项目已有16×16火焰素材，不承担伤害。改变喷射范围时同时调整粒子速度、寿命和spread以匹配视觉。
- WeaponSprite2D 未填贴图：作者可补喷火器外观，默认枪口朝右，跟随火焰方向。没有替代生成几何武器，也没有调用付费API。

## 实战检查
1. 使用控制台获得战锤，装备后观察力量与削韧倍率；造成多次破韧，状态栏层数增加且力量逐层+1。
2. 下一场战斗不保留上一场破韧力量；升级态破韧额外伤害受当前力量与目标减伤影响，不触发连锁破韧。
3. 装备喷火器，技能面板/战斗技能栏出现“喷射火焰”。开启后移动、旋转鼠标，喷射方向与角色位置持续跟随。
4. 持续喷射时点击/长按基础攻击均不能释放，能量也不被扣除；冲刺、暴怒等其他技能仍可释放。
5. 敌人处于喷火范围时约每秒5次跳伤并叠燃烧，离开范围或躲在墙后不再直接跳伤；原有燃烧继续按状态规则结算。
6. 五秒后或冻结/死亡/离场中断后，移动速度与基础攻击恢复。暂停时不推进生命周期，不会补发暂停期间伤害。
7. 使用备用弹药引起技能栏重建时仍能继续喷火；卸下喷火器后额外技能移除且不继续喷射。

编辑器资源接线检查脚本：`scripts/utils/hammer_flamethrower_editor_check.gd`。只加载资源并在场景树外检查配置，不运行非tool节点的技能方法、不启动游戏或写存档；物理命中、输入拦截、视觉和清场仍需作者实测。
