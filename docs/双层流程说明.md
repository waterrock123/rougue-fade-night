# 双层路线流程

- 第一层六列，第二层七列；每列仍随机生成 2–4 个可选房间，最右列为 Boss。
- 第一层 Boss 胜利后：升级奖励 → 修整期 → 离开修整期 → 第二层地图。
- 第二层 Boss 胜利后：沿用整局胜利、仓库回收与删除局内存档的流程。
- 换层不重建 RunStats，不重置生命、装备、技能、商店等级、天气及环境。修整期退出清空金币等原有规则不变。

## 配置入口

Run 的 `floor_configs` 按顺序引用 `custom_resource/run_floor_01.tres` 和 `run_floor_02.tres`。

每层可配置名称、列数、普通战斗等阶曲线及独立战斗池。战斗池留空时沿用 MapGenerator 的草原战斗池。Boss 固定抽取 tier 3；目前两层复用现有 Boss 池，未新增 Boss。

第一层普通战斗等阶为 0、0、1、1、2；第二层为 1、1、2、2、2、2。等阶来自既有战斗数据，不额外修改怪物属性。

## 存档与手动测试

当前楼层存入 RunStats，路线结构继续完整保存，不会在继续游戏时重新抽图。旧存档缺少楼层字段时视作第一层。

1. 新开局确认地图显示第一层，路线共六列。
2. 第一层 Boss 胜利确认进入升级奖励，而非通关回收。
3. 在该奖励界面退出并继续，确认奖励选项保持一致；选择奖励并离开修整期后应进入七列的第二层。
4. 第二层选择房间后退出并继续，确认楼层、路线、构筑与已选房间保持一致。
5. 第二层 Boss 胜利确认执行原有通关回收；返回后不可继续已通关的这局。

使用编辑器扫描检查，不自动启动游戏；完整游玩流程需手动测试。
