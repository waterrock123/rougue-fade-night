# 冰原三种小怪的 AI 动画素材

## 生成范围

本轮使用项目已有的 Meowa API 工具，没有调用其他生图服务。
用户预算上限 300 点；基础造型一批 20 点，十二段动画每段 15 点，总计 200 点。
不自动花完剩余 100 点，也不沿用其他任务的预算。

| 敌人 | 造型 | 动画 |
| --- | --- | --- |
| 霜牙猎犬 | 白色毛皮、青蓝冰牙、低伏四足猎犬 | 待机呼吸、原地跑动、扑咬、倒地死亡 |
| 冰晶哨兵 | 青色晶冠、深色石质躯干、小型浮游晶体守卫 | 待机悬浮、移动、三次施法手势、碎裂倒地 |
| 背冰兽 | 蓝色厚重四足兽、浅青冰晶背甲、短腿和前伸长鼻 | 慢速呼吸、沉重移动、前方挥击、倒地死亡 |

提示词与动作时间线保存在 `custom_resource/meowa_frost_*_20261015.json`。
候选任务、选用编号、动画任务和费用记录在 `custom_resource/meowa_frost_assets_20261015.json`。
每只都使用同一张 source.png 生成后续动作；没有把不同外观候选拼成假动画。

## 素材与绑定

三个目录分别为：

- `assets/enemy/frost_fang_hound/`
- `assets/enemy/frost_crystal_sentinel/`
- `assets/enemy/frost_shell_beast/`

每个目录保留首张参考图、透明动画原始文件、四张 PNG 图集、时长元数据，以及预览 GIF/JPG。
运行时只使用 PNG 图集，通过 `sprite_frames/<敌人名>_sprite_frames.tres` 播放。
所有帧保留统一 32×32 透明画布，不缩放原始像素、不逐帧裁切，保持原始帧时长。
`idle`/`walk` 循环，`attack`/`die` 不循环；死亡继续使用原 Enemy 清理逻辑。

新动画绑定到原先创建的三个冰原敌人场景，没有修改原大狗、骷髅和树精的美术资源。
只调整 AnimatedSprite2D 的显示比例与位置，不改变实体根缩放、属性、寻路、碰撞和受击范围。
移除占位的整体彩色叠加，保持原色显示，并使用最近邻过滤。

哨兵三连冰锥调用 `attack` 动画，不再调用原骷髅的 `slash`。
猎犬 `attack` 播放时长调为 0.65 秒，让扑咬姿势与短物理冲刺衔接；原始动画和帧时长文件仍保留。
如果重新运行导入器覆盖猎犬 SpriteFrames，需要将其 attack 速度重新设为约 12.307693，其他动画仍为 8。

## 测试方式

无需手动拖贴图，进入第二层即可看到新外观。
单独测试可按《冰原敌人首版与测试》配置固定生成一只对应敌人。
建议检查左右朝向、贴地位置、扑击/射击/挥击姿势、受击反馈以及死亡后正常消失。
首版是单套二维表现，不是八方向动画；背冰兽的冰壳防御仍使用既有色调与范围提示。

编辑器检查入口：`scripts/utils/frost_art_editor_check.gd`。
旧逻辑回归入口：`scripts/utils/frost_enemies_editor_check.gd`。
均不自动启动战斗，不读取或修改玩家存档。实际动作手感与视觉对齐仍需实战确认。
